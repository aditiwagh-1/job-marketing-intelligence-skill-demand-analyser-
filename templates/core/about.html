Modular 5-App Django Architecture

1. Core Module (`core`)

Handles landing page presentation, navigation shell, search bar routing, live metric aggregation counters, and static info pages.

2. Jobs Module (`jobs`)

Maintains normalized relational models for Jobs, Skills, Companies, and Saved Jobs. Implements multi-faceted search, salary sliders, and pagination.

3. Analytics Module (`analytics`)

Executes Pandas statistical pipelines: KPI aggregations, role distributions, skill demand frequency matrix, salary progression curves, and location intelligence.

4. Recommendations & ML Module (`recommendations`)

Powers the signature Skill Gap Analyzer, career pathway compatibility scoring, content-based job recommender, and Scikit-Learn Random Forest Salary Predictor.

5. Accounts & Profile Module (`accounts`)

Provides user authentication, profile management, interactive skill tag editor, target career goal configuration, and saved jobs bookmarks.
